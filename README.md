# C++ Learning

A small project for practicing C++ programming. The current example demonstrates
adding values to a `std::vector` and iterating over its elements.

## Build

Open `vector_demo.cpp` in VS Code and run the default C++ build task, or compile
it from a terminal with:

```sh
g++ -std=c++11 -Wall -Wextra -pedantic vector_demo.cpp -o vector_demo
```

Run the program with:

```sh
./vector_demo
```
